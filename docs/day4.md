# Day 4 – Cart, About & Contact Page Development
**Date:** July 23, 2026
**Module:** 1 (July 20 – July 26, 2026)

## Objective
Build three more core pages — the Cart page, About page, and Contact Us
page — keeping them fully responsive and consistent with the Homepage design.

## Work Completed

### 1. Cart Page (cart.html)
- Built the cart layout showing added items (image, name, price, quantity).
- Added an order summary section (subtotal, shipping, total).
- Made the layout responsive: table view on desktop, stacked labeled cards
  on mobile (each row shows "Product", "Price", "Quantity", "SubTotal" labels).

### 2. About Page (about.html)
- Built the About page with two alternating image/text sections introducing
  the brand and its values.
- Reused the shared navbar and footer for consistency.
- Made the sections stack vertically and center-align on mobile.

### 3. Contact Us Page (contact.html)
- Built the Contact form with fields: Name, Email, Subject, Message.
- Added a contact info section (social links, email) and an embedded map image.
- Made the layout responsive: form and contact info side-by-side on desktop,
  stacked on mobile.

### 4. Responsiveness Testing
- Tested all three pages across mobile, tablet, and desktop breakpoints.
- Fixed spacing and overflow issues found during testing.

## Decisions Made
- Cart page UI is static for now; will be connected to the Cart API in Module 3.
- Contact form is UI-only today; backend submission handling comes later
  in Module 3, alongside a Contact API.

## Next Steps (Day 5)
- Build the responsive Shop, Single Product, and Signup pages.
